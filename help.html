How it works

3 ステップで、計画が見える

ガントチャートを手で引く必要はありません。計画づくりは AI に、見える化はビューアーに任せます。

1

AI に頼む

下のプロンプトとスキーマを AI に渡し、「こんな計画を作って」と書くだけ。

2

JSON を保存

AI が出力した JSON を .json ファイルとして保存します。

3

ビューアーで開く

「ファイルを開く」で選ぶか、画面にドラッグ＆ドロップ。すぐにガントチャートになります。

そのあとは AI に「この JSON の○○を直して」と頼むだけ。ファイルが書き換わると、ビューアーが自動で読み直します。

Features

見るだけで、状況がわかる

報告資料を作らなくても、この画面を見せれば話が通じる。そのための表現を詰め込みました。

予実 × イナズマ線

「どこが遅れているか」が線で見える

予定の枠の中に、実績と進捗を塗りで重ねます。紫のイナズマ線は各タスクの進み具合を本日線から結んだもので、左に出っ張っている所が遅れです。

  • 順調・要注意・遅延・完了を自動で色分け
  • 依存関係は矢印で、クリティカルパスは赤で強調
  • 予定より遅れて終わった分は赤くはみ出して表示
複数プロジェクト

全社のプロジェクトを、一つの時間軸で

いくつものプロジェクトを縦に並べて俯瞰できます。階層は何段でも OK。「PJ / 工程 / 全て」のボタンで、見たい粒度に一瞬で切り替えます。

  • 完了したプロジェクトは自動でグレー＋「✓ 完了」表示
  • 見ないプロジェクトは一時的に非表示にできる
  • 折りたたみ状態はファイルごとに記憶
編集モード

その場で直して、元の JSON に保存

「編集」に切り替えると、表計算のようにセルを直接書き換えられます。バーをドラッグすれば日程が動き、Ctrl+S で元のファイルに上書き保存。

  • 行の追加・削除・並べ替え、Tab で階層を下げる
  • 詳細パネルで依存関係・クリティカル・備考を編集
  • Ctrl+Z で何度でも元に戻せる
稼働日カレンダー

祝日も休日出勤も、そのまま描ける

日・週・月の 3 つの尺度を切り替えられます。日単位では週末と祝日に網掛けをし、ホバーで祝日名を表示。土日稼働や特別稼働日も JSON で指定できます。

  • 期間は「暦日／稼働日」を併記
  • 横幅は 50%〜300% でズーム
デザイン

会議室のモニターでも、手元でも

「クリーン・デンス・ダーク」の 3 スタイルと 11 色の配色を自由に組み合わせられます。行間や表示する列・レイヤーも好みに合わせて。設定はブラウザが覚えています。

AI Prompt

AI に渡すプロンプト

コピーして、最後の「作りたい内容」だけ書き換えてください。スキーマとサンプルも一緒に渡すと精度が上がります。

あなたはガントチャート用の JSON を生成するアシスタントです。 添付の JSON Schema（schema.json）に厳密に従い、JSON を1つだけ出力してください。 サンプル（sample-data.json）の作り方を参考にしてください。 制約: - 出力は JSON のみ。前後の説明文やコードフェンス外のテキストは書かない。 - 日付はすべて YYYY-MM-DD 形式。 - 階層は children の再帰（任意の深さ）。children を持つ行はグループで、 バー・工数・進捗は配下から自動集計されるため plan 等を書かない。 - children の無い行はタスクで、plan（予定期間）が必須。 未着手のタスクは actual を {"start": null, "end": null} とする。 - progress は 0〜1 の小数（% ではない）。actual.end に日付を入れた完了タスクは progress を必ず 1 にする（矛盾させない）。 - deps には実在するタスク id のみを書く（依存は FS: 先行の終了→自分の開始 のみ）。 - critical: true を付けるタスクは deps で連結した一続きの鎖にする。 - 任意フィールドは、値が無ければ省略してよい（無理に埋めない）。 作りたい内容: <ここに計画の中身を書く。例: 新規Webサービスの開発計画。企画→設計→開発→テスト→リリースの5工程、期間は2026年8月〜12月、担当は3名。>
schema.json をダウンロード sample-data.json をダウンロード データ形式の解説を読む
FAQ

よくある質問

データはどこかに送信されますか？

いいえ。JSON はブラウザの中だけで読み込み・表示・保存されます。github.io 版でも、ファイルの中身がサーバーに送られることはありません（フォントの読み込みだけ外部に接続します）。

保存ボタンを押すとダウンロードになってしまいます

Safari / Firefox では元のファイルへの上書きができないため、ダウンロードとして保存されます。上書き保存したい場合は Chrome / Edge をお使いください。

ページを再読み込みするたびにファイルを選び直すのが面倒です

Chrome / Edge なら「↺ 前回: ファイル名」ボタンでワンクリックで開き直せます。許可ダイアログで「サイトの閲覧中は常に許可」を選ぶと、次からは自動で開きます（file:// で開いている場合は、この選択肢が出ないことがあります）。

祝日は自動で入りますか？

入りません。国や会社によって休みが違うため、JSON の calendar.holidays に書く方式です。AI に「2026年の日本の祝日も calendar に入れて」と頼むのが簡単です。

AI が書き換えた内容がすぐ反映されません

Chrome / Edge で「ファイルを開く」から開いた場合は、数秒以内に自動で読み直します。それ以外の開き方をした場合は、ファイル名の横の ⟳ ボタンを押してください。編集中で未保存の変更があるときは、上書きせずに通知だけ出します。

英語でも使えますか？

使えます。⚙ メニューから言語を English に切り替えられます。タスク名などは JSON の ja / en に書かれたものが表示されます。
